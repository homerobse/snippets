## `__init__.py` files 
The presence of the `__init__.py` didn't make any difference for the import results.

The code inside `__init__.py` is run whenever any module inside the package folder is imported using an 
import statement that makes reference to the `pkg_imported` package. If it is just 
`from module_imported import useful_func`, then it won't run the `__init__.py`

# Relative import

When you run `import my_module` it assumes `my_module` is findable in sys.path (PYTHONPATH)

A relative import is relative to the current package (i.e. the folder where the current file is in), even if that folder is not directly in the PYTHONPATH.

Python uses dots to specify the level of the parent directory in `from ..xxx import xxx` statements, but not with a bare `import ..xxx`

In relative imports to the parent folder `from ..parent_folder import module_root` the python call has to be done from above the parent folder, i.e. `$ python -m parent_folder.pkg_a.module_root_relative_importer`.
